# Module kite3d

3D maths for Kotlin Multiplatform: three.js's `src/math` layer in common Kotlin.

Vectors, matrices, quaternions, Euler angles, bounding volumes, ray and plane
intersection, frustum culling, spherical and cylindrical coordinates, colour
with colour-space management, and keyframe interpolants. Maths only: there is
no scene graph, geometry or renderer. Depends on `kotlin-stdlib` alone.
