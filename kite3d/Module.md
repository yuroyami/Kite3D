# Module kite3d

3D maths for Kotlin Multiplatform, with the same API as three.js.

Vectors, matrices, quaternions, Euler angles, bounding volumes, ray and plane
intersection, frustum culling, spherical and cylindrical coordinates, colour
with colour-space management, keyframe interpolants, and a camera that projects
points to the screen. Maths only: there is no scene graph, geometry or renderer.
Depends on `kotlin-stdlib` alone.
